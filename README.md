# Agent Office

Claude와 Codex가 한 팀으로 일하는 작업 공간이에요.
할 일을 보내면 둘이 나눠서 처리하고 결과를 알려 줘요.

## 시작하기 전에 확인하세요

- Windows라면 WSL이 필요해요. Linux와 macOS 13.3 이상에서도 쓸 수 있어요.
- Linux는 Ubuntu 24.04 이상을 권장해요.
- 맥은 Apple Silicon과 Intel을 지원해요. Python 3.11 이상이 필요해요.
- 맥에서 필요한 프로그램을 함께 설치하려면 [Homebrew](https://brew.sh)를 먼저 설치하세요.
- 인터넷에 연결되어 있어야 해요.
- Claude 계정과 ChatGPT 계정이 있어야 해요.

Windows에서 WSL이 없다면 먼저 설치하세요. 설치 중에 관리자 권한이나 재부팅이 필요할 수 있어요.

맥 지원은 모의 환경에서 확인했어요. 실제 맥에서 설치와 화면 실행은 아직 확인하지 못했어요.

### 맥에서 달라지는 점을 확인하세요

- Chrome이나 Edge가 있으면 앱 창으로 열려요. 없으면 기본 브라우저로 열려요.
- 파일과 폴더는 Finder에서 열려요.
- 맥에는 사용량 제한, 디스크 줄이기, 바탕화면 바로가기가 없어요. 설정에도 보이지 않아요.
- Claude의 남은 사용량은 Claude가 값을 알려 줄 때만 보여요.

## 설치하기

터미널에 아래 명령을 붙여 넣으세요.

```sh
curl -fsSL https://raw.githubusercontent.com/mjsob/agent-office/main/get.sh | bash -s -- --apply --install-system-deps
```

설치가 끝나면 Office가 바로 열려요.
로그인이 필요하면 터미널에 안내가 나와요. 안내에 따라 로그인하세요.

설치 전에 무엇이 바뀌는지 먼저 보고 싶다면 아래 명령을 쓰세요. 아무것도 설치하지 않아요.

```sh
curl -fsSL https://raw.githubusercontent.com/mjsob/agent-office/main/get.sh | bash
```

### 설치하면 이렇게 돼요

- Claude Code와 Codex CLI가 없으면 함께 설치돼요.
- 작업 폴더 `~/agent-office`가 만들어져요.
- 설치 안내에 따라 PATH를 설정하면 새 터미널에서 `office` 명령으로 실행할 수 있어요.
- Python이나 git이 없으면 Linux는 apt로, 맥은 Homebrew로 설치돼요. 이때 관리자 비밀번호를 물어볼 수 있어요.

## 실행하기

```sh
office
```

새 터미널을 열고 `office`를 입력하면 Office가 열려요.
`~/agent-office` 폴더에서 일을 시작해요.

다른 폴더에서 일하려면 폴더 경로를 함께 입력하세요.

```sh
office ~/내프로젝트
```

- 폴더가 없으면 열리지 않아요. `mkdir`로 먼저 만드세요.
- 대화 기록과 작업 파일은 폴더마다 따로 저장돼요.
- 설치한 버전은 `office --version`으로 확인할 수 있어요.
- 예전 폴더의 대화를 가져오려면 `office import ~/예전폴더`를 입력하세요. 이미 가져온 대화는 건너뛰어요.

### 화면에서 진행 상황 확인하기

- 콘솔 배터리는 남은 사용량을 보여 줘요.
- 오늘 메시지는 시각만 보여 줘요. 지난 메시지는 날짜도 함께 보여 줘요.
- 좁은 화면에서도 요청 상태와 자동 재시도 안내를 볼 수 있어요.

## 업데이트하기

새 버전이 나오면 Office 화면에 알림이 떠요.
**업데이트**를 클릭하면 새 버전을 설치하고 Office를 다시 시작해요.
에이전트가 일하는 중에는 업데이트할 수 없어요. 작업이 끝난 뒤 클릭하세요.

이미 설치했거나 업데이트 알림이 뜨지 않으면 터미널에서 아래 명령을 실행하세요.

```sh
curl -fsSL https://raw.githubusercontent.com/mjsob/agent-office/main/get.sh | bash -s -- --apply
```

처음 설치할 때 `--prefix`나 `--workspace`로 경로를 바꿨다면 같은 옵션을 붙이세요.
예전 버전도 이 명령으로 점검할 수 있어요. 수정 보존을 확인할 수 없으면 설치를 멈춰요.
설치가 끝나면 새 버전의 Office가 바로 열려요.
이전 버전이 켜져 있으면 끄고 새 버전으로 다시 열어요.
에이전트가 일하는 중이면 이전 버전을 그대로 두고 안내만 나와요.
작업이 끝난 뒤 `office`를 다시 실행하면 새 버전으로 바뀌어요.
작업 파일과 대화 기록은 그대로 남아요.

### 직접 고친 부분을 유지하며 업데이트하기

새 버전과 서로 겹치지 않는 수정은 자동으로 합쳐요.
합친 사본을 실행해 기본 동작을 확인한 뒤 설치해요.
같은 부분을 서로 다르게 바꿨다면 처리 방법을 선택하세요.

| 선택 | 바뀌는 동작 |
|---|---|
| **내 수정 유지** | 업데이트를 보류하고 지금 버전과 수정을 그대로 유지해요. |
| **합쳐 보기** | 로그인한 에이전트가 별도 사본에서 합쳐요. 작업이 끝나면 결과를 확인하고 적용할지 선택해요. |
| **새 버전 사용** | 겹치는 내 수정은 백업하고 새 변경으로 바꿔요. 겹치지 않는 수정은 유지해요. |

사본을 합쳤더라도 모든 기능이 자동으로 검증되는 것은 아니에요.
에이전트의 변경 설명과 시험 결과를 확인하고 **합친 버전 적용**을 누르세요.
다시 합쳐야 하면 이전 사본을 보관하고 새 사본으로 시도할 수 있어요.

0.8.x나 0.9.0에서 충돌이 나면 별도 선택 창이 열릴 수 있어요.
Office가 켜져 있으면 선택과 사본 검사까지만 해요.
적용 방법을 고르면 이어서 실행할 명령을 안내해요.
Office를 닫은 뒤 안내한 명령을 실행하면 저장한 선택과 사본을 이어받아요.
창이 열리지 않으면 작업을 마친 뒤 아래 명령으로 이전 화면을 여세요.
설치 경로를 바꿨다면 처음 설치할 때 쓴 경로 옵션도 함께 넣으세요.

```sh
curl -fsSL https://raw.githubusercontent.com/mjsob/agent-office/main/get.sh | bash -s -- --apply --review
```

삭제한 파일이나 예전 원본을 알 수 없는 수정은 자동으로 합치지 않아요.
링크나 폴더로 바꾼 파일과 직접 고친 실행기는 덮지 않고 멈춰요.
이 PC 전용 버전인 `+local`도 공개 버전으로 바꾸지 않아요.
이때는 안내를 확인하고 에이전트에게 수정을 옮기는 작업을 맡기세요.

업데이트 전 설치 파일은 백업해요.
설치기가 만든 백업은 최근 10개를 보관해요.
사용자가 만든 백업 폴더와 예전 표시 없는 백업은 정리하지 않아요.
대화와 작업 파일은 설치 파일과 따로 유지해요.

## 에이전트 권한

Claude와 Codex는 권한 확인 없이 실행돼요.
작업 폴더 밖의 파일도 읽고 고칠 수 있어요.

권한을 작업 폴더 안으로 제한하려면 이렇게 실행하세요.

```sh
OFFICE_SANDBOX=1 office
```

## 설치 옵션

`bash -s --` 뒤에 붙여서 써요.

| 옵션 | 설명 |
|---|---|
| `--apply` | 실제로 설치해요. 없으면 미리 보기만 해요. |
| `--install-system-deps` | Python·git이 없으면 함께 설치해요. |
| `--workspace 경로` | 작업 폴더를 바꿔요. `/`로 시작하는 전체 경로로 입력하세요. 기본값은 `~/agent-office`예요. |
| `--prefix 경로` | 프로그램 설치 폴더를 바꿔요. `/`로 시작하는 전체 경로로 입력하세요. 기본값은 `~/.local/share/office-app`이에요. |
| `--skip-login` | 로그인을 건너뛰어요. |
| `--review` | 자동으로 합칠 수 없는 수정이 있으면 별도 선택 화면을 열어요. `--apply`와 함께 쓰세요. |
| `--device-auth` | 브라우저 대신 기기 코드로 Codex에 로그인해요. |
| `--no-launch` | 설치가 끝나도 Office를 열지 않아요. |

## 이미 쓰던 환경은 그대로 둬요

- 이미 설치된 Claude Code와 Codex CLI는 다시 설치하지 않아요.
- 이미 로그인되어 있으면 그 계정을 그대로 써요.
- 이 설치기가 만든 `office` 명령은 업데이트해요. 직접 만들거나 고친 명령은 그대로 둬요.
- `.bashrc` 같은 설정 파일은 고치지 않아요.

## 문제가 생겼을 때

**연결 오류 뒤에 자동 재시도 안내가 나와요**
연결이 복구될 때까지 기다리세요.
일시적인 연결 오류는 15초, 60초, 180초 뒤에 최대 세 번 다시 시도해요.
로그인 오류나 사용량 한도는 자동으로 다시 시도하지 않아요. 화면 안내를 확인하세요.

**요청 진행이 멈췄다는 알림이 나와요**
요청 상태와 에이전트 안내를 확인하세요.
3분 동안 진척이 없으면 알림이 나오고 리더가 상태를 점검해요.
일시정지한 에이전트가 있다면 재개하세요.

**업데이트했는데 이전 화면이 그대로 보여요**
에이전트가 작업 중인지 확인하세요.
작업이 끝나면 `office`를 다시 실행하세요.

**업데이트 전 설치로 되돌리고 싶어요**
버전 표시를 눌러 업데이트 창을 여세요.
백업이 있으면 **이전 설치로 되돌리기**를 선택할 수 있어요.
설치 파일만 되돌리고 대화와 설정은 유지해요.
업데이트 뒤 앱 폴더에 파일을 추가하거나 고쳤다면 덮지 않고 멈춰요.
에이전트에게 새 수정을 보존하면서 되돌리는 작업을 맡기세요.

**합치기 버튼을 누를 수 없어요**
Claude나 Codex에 로그인했는지 확인하세요.
에이전트를 직접 일시정지했다면 다시 시작하세요.
옛 버전의 별도 선택 화면에서 합치려면 Office도 켜져 있어야 해요.
원본을 확인할 수 없는 파일은 자동으로 합칠 수 없어요.

**`office`를 실행하면 예전 Office가 열려요**
설치 명령을 다시 실행하세요.
다른 `office` 명령이 먼저 실행되면 설치가 끝날 때 그 파일 위치를 알려 줘요.
안내된 파일을 지우거나 이름을 바꾸세요.

**`office` 명령을 찾을 수 없어요**
새 터미널을 열고 다시 입력하세요.
맥에서 기본 zsh를 쓰면 `~/.zprofile`에 아래 줄을 추가하고 새 터미널을 여세요.

```sh
export PATH="$HOME/.local/bin:$PATH"
```

바로 실행하려면 `~/.local/share/office-app/bin/office`를 입력하세요.

**Codex 로그인 화면이 열리지 않아요**
설치 명령 끝에 `--device-auth`를 붙여 다시 실행하세요.

**로그인이 풀렸어요**
Office 대화에 `로그인 해줘`라고 보내세요.
Claude와 Codex가 각자 로그인 링크를 채팅에 올려요.
Claude는 로그인 뒤 나온 코드를 채팅에 붙여 넣으면 연결돼요.
Codex는 이 PC 브라우저에서 링크를 열면 바로 연결돼요.

**Claude에 로그인되지 않아요**
터미널에서 `claude auth login`을 실행하세요.
로그인 상태는 `claude auth status`로 확인할 수 있어요.

**인증서 오류가 나요**
Office는 시스템에 등록한 인증서를 함께 읽어요.
맥 키체인에만 등록한 인증서는 읽지 못해요.
그래도 오류가 나면 `SSL_CERT_FILE` 환경변수에 인증서 파일 경로를 넣으세요.
`office stop`으로 Office를 끈 뒤 다시 실행해야 적용돼요.

**맥에서 다른 설치기가 실행 중이라고 나와요**
실행 중인 설치가 끝날 때까지 기다리세요.
설치기를 강제로 종료했다면 실행 중인 설치기가 없는지 먼저 확인하세요.
그다음 `~/.local/share/office-app/.install.lock.d` 폴더를 지우고 다시 설치하세요.
설치 경로를 바꿨다면 그 경로 안의 `.install.lock.d` 폴더를 지우세요.

**Python 버전이 낮다고 나와요**
Python 3.11 이상을 설치하세요.
맥에서는 Homebrew를 설치한 뒤 설치 명령에 `--install-system-deps`를 붙여 다시 실행하세요.
Ubuntu를 새로 설치한다면 24.04 이상을 권장해요.

## 삭제하기

1. `~/.local/share/office-app` 폴더를 지우세요.
2. 설치할 때 만들어진 `~/.local/bin/office` 파일을 지우세요.

기본 작업 폴더 `~/agent-office`와 대화 기록은 남아요. 필요 없다면 직접 지우세요.
작업 폴더를 설치 폴더 안으로 바꿨다면 지우기 전에 백업하세요.
Claude Code, Codex CLI와 로그인 정보도 그대로 남아요.
